# Warcraft Heroes Handbook 3.0 compendium for FoundryVTT

**Compatibility with FoundryVTT**

Minimum: 10.303

Verified: 12.331
> ⚠️ Requires *dnd5e* system

**Made by WC5e discord community. Authors: @viktoorfrankenstein, @intervencion, @teswa, @junkturkey**

## Installation

Simply install this module via manifest url: `https://github.com/JunkTurkey/warcraft-5e-fvtt/releases/latest/download/module.json`

Enable it in your game world and navigate to compendiums tab

## Contribution

You can anytime contribute via pull requests. 

Alternatively, if you are not familiar with git, you can contact me in discord `@junkturkey`, hitting in DMs or on WC5e server
We are running a separate foundry world you can use for changing items inside. I will commit and release the changes.

Use following rules for contribution using our server:
1. Import the item you want to work on from compendium. You cannot edit items inside of a compendium, so you have to import them first and edit them under "Items" tab
2. Make your changes to the item under root of `Items` tab
3. Once it is ready, move the item under `Release` folder in the `Items` tab
4. Follow the compendium style of folder breadcrumbs inside `Release` folder. For example, if you want to release blood death knight class feature - under `Release` folder create a folder named `Class Features`, then create `Death Knight` folder inside, then create `Blood` folder inside and go on. We will need that for following items organization, as unfortunately all items will be moved to the compendium manually
5. Once ready, please hit me in discord. I will move your items into compendium and create a release
